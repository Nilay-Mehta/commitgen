The hosted page above is ready to use as a portfolio demo. These commands are for running the real quantized model through Ollama and using commitgen inside a Git repo. 

# One-time local model setup
ollama create commitgen -f deployment/Modelfile

pip install -e deployment

git add .
commitgen commit
# Optional: local web wrapper with live Ollama calls
# Start this from the repo root:
python -m http.server 8000

# Then open:
http://localhost:8000/web/
Hosted demo uses a browser preview. Local setup runs the fine-tuned model through Ollama with no cloud inference.
